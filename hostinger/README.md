# Hostinger deployment root

Selecione a pasta `hostinger` como **Diretório raiz** no painel da Hostinger.

- Build: `npm run build`
- Start: `npm start`
- Entry file: `server.js`
- Node.js: `22.x`

Esta pasta apenas adapta a estrutura do projeto ao seletor de diretório raiz da Hostinger. O código principal permanece na raiz do repositório.
